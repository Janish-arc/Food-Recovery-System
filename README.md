# 🍔 Food Delivery Application

A full-stack food delivery web application built using the **MERN Stack (MongoDB, Express.js, React.js, Node.js)**. The platform connects customers with restaurants, providing a seamless experience for discovering restaurants, exploring food menus, placing orders, and managing deliveries.

## 🚀 Features

### 👤 Authentication & Authorization
- Secure user registration and login.
- JWT-based authentication.
- Role-Based Access Control (RBAC).
- Protected routes and API endpoints.
- Role-based access for customers, restaurants, and delivery partners.

### 🏪 Restaurant Management
- Browse available restaurants.
- View individual restaurant details.
- Explore restaurant menus.
- Manage restaurant information.

### 🍕 Food & Menu Management
- Browse food items across restaurants.
- View detailed food information.
- Explore food categories.
- Dynamic food listings and filtering.
- Cloudinary integration for image uploads.

### 🛒 Cart Management
- Add food items to cart.
- Update item quantities.
- Remove items from cart.
- Calculate subtotal, delivery fees, taxes, and total.
- Restrict cart items to a single restaurant at a time.

### 📦 Order Management
- Place food orders.
- Manage order details.
- Track order status.
- Handle order-related operations.

### ⭐ Reviews & Ratings
- Submit restaurant reviews.
- Provide food and order feedback.
- Manage customer reviews.

### 📱 Responsive UI
- Responsive interface for different screen sizes.
- User-friendly navigation.
- Interactive restaurant and food browsing experience.

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate to the Project

```bash
cd YOUR_PROJECT_FOLDER
```

### 3. Install Backend Dependencies

```bash
cd backend
npm install
```

### 4. Install Frontend Dependencies

```bash
cd ../frontend
npm install
```

### 5. Configure Environment Variables

Create a `.env` file in the backend directory and configure the required environment variables, including:

- MongoDB connection string
- JWT secret
- Cloudinary credentials
- Port configuration
- Cookie configuration

Use the actual variable names defined in your application.

### 6. Run the Application

Start the backend and frontend in separate terminals using the development scripts configured in their respective `package.json` files.

```bash
npm run dev
```
